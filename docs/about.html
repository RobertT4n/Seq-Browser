Seq-Browser

How the catalogue is built.

TableAnalysisAbout

Why

New sequencing assays appear every week, across bulk, single-cell and spatial genomics, and many are named only deep inside a paper's Results section. Seq-Browser keeps one curated, searchable list of them, readable by people and by language models.

How it works

  1. Collect. Every new bioRxiv/medRxiv preprint and every new PubMed journal paper, via their public APIs, with full text where it is open access.
  2. Filter. Free rule-based triage cuts ~1,200 papers a week to ~100 candidates. It reads abstracts and scans full text for naming phrases (“an approach we call …”), which catches methods introduced only in the Results.
  3. Classify. A language model reads each candidate and decides whether it introduces a new sequencing method, wet-lab or computational, and tags it, quoting the sentence that justifies each call.
  4. Review. A human approves or rejects each candidate before it enters the list.
  5. Publish. The approved list rebuilds this website, a Markdown table and JSON/CSV downloads automatically.

Labels

Readout
What is measured: 3D genome, RNA, chromatin accessibility, histone modifications, DNA methylation…
Resolution
Bulk, single-cell, spatial or subcellular.
Scope
Genomic coverage: genome-wide, or targeted to chosen loci (capture, viewpoints). Selecting a place in a tissue is resolution, not scope.
Chemistry
Key molecular steps: proximity ligation, MNase, Tn5, antibody-tethered enzymes, droplets…
Variant of
The parent method(s), e.g. RCMC → Micro-C.

Computational methods are being collected and will appear once curated.

Using it with an LLM

Point your assistant at the Markdown masterlist, which is the whole database in one file, or at llms.txt. It won't need to search the web.

Contribute

Missing a method or spotted a wrong label? Open an issue or pull request on GitHub. Each method is one small YAML file in masterlist/methods/.
