# Week 2026-10-20 -> 2026-10-26: papers the classifier was unsure about

273 candidates -> 10 new wet-lab methods, 35 new computational tools, 21 unsure (below). Decide and move on.

- [ ] **MINT Block: multivariate integration across independent studies to identify multi-omics signatures** - doi:10.64898/2026.10.13.758954  
  MINT Block is a general multi-omics integration statistic; unclear whether it is sequencing-specific or just general omics (sequencing-based dry method only if counted as such).
- [ ] **Decoding pseudoexon activation by deep intronic variants using a high-throughput minigene assay in the NF1 gen** - doi:10.64898/2026.10.20.760351  
  High-throughput minigene splicing assay with NGS readout for NF1 intron 3; unclear whether this is a new general sequencing assay or an application of minigene and NGS to one gene.
- [ ] **Optimal transport reveals unresolved cells in single cell multi-omics** - doi:10.64898/2026.10.15.759426  
  Abstract describes an ensemble optimal-transport coupling and a group-vote ambiguity score but gives no method name, and much of the paper is a benchmark of existing tools; unclear whether these count as one new named computational method.
- [ ] **A statistical framework for system-level synthesis** - doi:10.64898/2026.10.19.760244  
  Introduces SS-ANOVA-SVD for high-dimensional biological profiles, but the abstract never says the data are sequencing-based, so it is unclear whether it is a dry sequencing method.
- [ ] **GENOAR: Global Engine for Navigating the Omnicell space via Agent-based Research** - doi:10.64898/2026.10.15.759380  
  Mixes a scRNA-seq atlas resource (54 million cells) with a preprocessing and agent software engine; unclear whether the software is the paper's new method or just the infrastructure for the atlas.
- [ ] **Single-Amplicon Sequencing of Coding-Complete Enteroviruses and Rhinoviruses Genomes from Clinical Specimens** - doi:10.64898/2026.10.19.760066  
  Abstract says a single-amplicon PCR and sequencing workflow was developed, but it is unclear whether it is a new method or an application of known amplicon sequencing with a new primer set.
- [ ] **GeoSinkhorn Flow: Geometry-Aware Flow Matching for Perturbation-Conditioned Dynamics in Single cell Data Pheno** - doi:10.64898/2026.10.16.759724  
  New computational method for single-cell data, but it is applied to synthetic, CyTOF and Perturb-seq data, so it is unclear whether it is specific to sequencing data.
- [ ] **Data mining of global sequence datasets markedly expands known diversity within the Tobamovirus genus** - doi:10.64898/2026.10.22.760918  
  Primarily a viral discovery study; it also builds a Snakemake pipeline and a two-stage ML contig classifier, and it is unclear whether these are the paper's method contribution or incidental tools.
- [ ] **Denoising single-cell ATAC-seq data with Shannon entropy** - doi:10.64898/2026.10.20.760589  
  Clearly a new computational nucleus-filtering method for scATAC-seq, but the abstract gives no method name and the preprint did not resolve in Europe PMC, so the entry could not be validated; needs a name and reference check.
- [ ] **Robust and accessible in situ sequencing with an open-source automated sequencer** - doi:10.64898/2026.10.18.759961  
  Open-source automation of existing in situ sequencing chemistry (fluidics, heating, imaging); unclear whether an instrument/automation platform counts as a new wet-lab sequencing method rather than an implementation of existing chemistry.
- [ ] **An integrative cardio-informatics approach identifies positionally conserved ancestors of human lncRNA genes t** - doi:10.64898/2026.10.21.759660  
  Unclear whether a genome-annotation neural network web tool (VertLncRNAchecker) counts as a computational method for analysing sequencing data; it operates on genomic regions and synteny, not reads, so it may be out of scope.
- [ ] **Differential k-mer distributions enable identification of tetrapod subterminal heterochromatin** - doi:10.64898/2026.10.19.760198  
  A k-mer based algorithm is developed for genome assemblies, but the abstract gives it no name and it is unclear whether it counts as a sequencing-data method.
- [ ] **Early Prenatal Cell-Free DNA Methylation Landscape Informs Epigenetic Purification of the Circulating Fetal Ge** - doi:10.64898/2026.10.20.760549  
  Abstract says epiSIFT was adapted as a genome-wide assay; unclear whether epiSIFT is prior published work (then this is a use or modification) or a new named method for this paper, and I could not check the source.
- [ ] **Decoding & manipulating human intercellular signaling via scalable cell-free protein synthesis** - doi:10.64898/2026.10.24.761585  
  Main platform is cell-free protein synthesis (not sequencing), and it also reports a cytokine scRNA-seq dataset and computational prioritisation methods, but none are named; whether any counts as a new sequencing method needs a full-text check.
- [ ] **Si-scRNA-seq: Enabling ambient-stable single-cell transcriptomics through spatially confined biosilicification** - doi:10.1073/pnas.2617730123  
  Biosilicification is a sample-preservation chemistry enabling scRNA-seq after ambient storage; unclear whether it is a new library-prep method or a storage protocol around existing platforms.
- [ ] **Defining early human developmental identity: A curated, cross-platform marker framework.** - doi:10.1016/j.stemcr.2026.103123  
  DeepDiff is a web resource for fate classification from transcriptomes, but the abstract frames the main contribution as a marker panel; unclear whether DeepDiff is a new analysis method or a resource.
- [ ] **MAJIQ V3: Scalable and accurate RNA splicing analysis with splicegraph algebra and improved intron retention m** - doi:10.1093/nargab/lqag126  
  New major version of the existing MAJIQ splicing tool with a new intron-retention model; MAJIQ V1/V2 are not in the database, so unclear whether a version update counts as a new method or whether MAJIQ itself should be added as one entry. Needs user decision.
- [ ] **CauTrigger: deciphering biological system state transitions by hierarchical causal decomposition.** - doi:10.1038/s41592-026-03274-9  
  New computational causal-discovery model, but it is general-purpose (synthetic data, single-cell multi-omics, microbiome) rather than specifically for sequencing data, so the NEW_DRY criterion is unclear. User should decide.
- [ ] **From SELEX to Sequencing: Uncovering enriched Aptamers with Next-Generation Sequencing and Bioinformatics.** - doi:10.1093/bioinformatics/btag777  
  Presents an NGS-plus-bioinformatics workflow for SELEX pools, but it combines standard tools (clustering, MSA, phylogeny) and the abstract does not show whether a new computational method is the contribution.
- [ ] **The landscape of gene loss and missense variation across the mammalian tree informs on gene essentiality.** - doi:10.1038/s41588-026-02783-9  
  Introduces two cross-species gene constraint metrics derived from mammalian genome/variant data; unclear whether a comparative-genomics scoring metric falls within the sequencing-analysis-tool scope of this database. Needs a decision from the curator.
- [ ] **The revised diploid genome sequence of an individual human: A workflow for near telomere-to-telomere assemblie** - doi:10.1073/pnas.2616836123  
  Title claims a workflow, but the abstract describes a genome re-assembly using existing hifiasm on ONT simplex reads; unclear whether the workflow is a new method or an application of existing tools. Needs curator check of the full text.
